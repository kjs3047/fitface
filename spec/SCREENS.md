# FitFace Screens

## 1. Splash Screen

### 목적

앱 초기화, 로컬 저장소 초기화, 사용자 얼굴 등록 여부 확인.

### 동작

1. Hive 또는 로컬 저장소 초기화
2. 사용자 프로필 존재 여부 확인
3. 얼굴 오버레이 이미지가 있으면 `CameraMatchScreen`으로 이동
4. 없으면 `OnboardingScreen`으로 이동

## 2. Onboarding Screen

### 목적

앱 사용 목적과 얼굴 사진 등록 필요성을 안내합니다.

### 필수 문구

```text
옷매장에서 실제 옷을 비추고, 내 얼굴을 겹쳐 어울림을 확인해보세요.
정면 얼굴 사진을 등록하면 매장 카메라 위에 얼굴을 띄울 수 있습니다.
```

### UI 요소

- 앱 로고/이름
- 간단한 설명 2~3줄
- `내 얼굴 등록하기` 버튼

## 3. Face Register Screen

### 목적

사용자의 얼굴 사진을 선택하거나 촬영합니다.

### UI 요소

- 갤러리에서 선택 버튼
- 카메라로 촬영 버튼
- 등록 가이드 문구

### 사진 가이드

```text
- 정면을 바라본 사진을 사용하세요.
- 얼굴부터 목까지만 보이는 사진이 좋습니다.
- 너무 어둡거나 강한 색조명이 있는 사진은 피하세요.
- 배경은 자동으로 제거됩니다.
```

## 4. Face Crop Screen

### 목적

사용자가 얼굴부터 목까지만 남기도록 크롭합니다.

### UI 요소

- 이미지 미리보기
- 얼굴~목 가이드 박스
- 크롭 UI
- `다음` 버튼
- `다시 선택` 버튼

### MVP 처리

배경 제거 자동 구현이 어렵다면 다음 순서로 구현합니다.

1. 우선 크롭 이미지를 그대로 오버레이로 사용
2. `BackgroundRemovalService` 인터페이스 생성
3. `MockBackgroundRemovalService`는 입력 이미지를 그대로 반환
4. 나중에 실제 배경 제거 로직으로 교체

## 5. Face Preview Screen

### 목적

배경 제거 결과를 확인하고 저장합니다.

### UI 요소

- 배경 제거된 얼굴 이미지 미리보기
- 체크무늬 배경
- `이 사진 사용하기` 버튼
- `다시 자르기` 버튼
- `다시 선택` 버튼

### 동작

1. overlayFaceImagePath 저장
2. userProfile 업데이트
3. 기본 OverlayPreset 생성
4. CameraMatchScreen 이동

## 6. Camera Match Screen

### 목적

후면 카메라 위에 얼굴 오버레이 이미지를 표시하고 사용자가 옷과 맞춰볼 수 있게 합니다.

### 화면 구조

```text
┌────────────────────────────┐
│ 상단: FitFace / 비교 / 설정 │
├────────────────────────────┤
│                            │
│        Camera Preview       │
│                            │
│       [Face Overlay]        │
│   drag / pinch / opacity    │
│                            │
├────────────────────────────┤
│ 투명도 Slider               │
│ [초기화] [AI판단] [스냅]     │
└────────────────────────────┘
```

### 필수 기능

- 후면 카메라 기본 실행
- 카메라 권한 요청
- 권한 거부 시 안내 화면 표시
- 카메라 초기화 실패 시 재시도 버튼 표시
- 등록된 얼굴 PNG 표시
- 드래그 이동 가능
- 핀치 확대/축소 가능
- 투명도 슬라이더 적용
- 초기값: scale 1.0, opacity 0.85
- 위치 초기값: 화면 중앙 상단 35% 지점

### 제스처

- 드래그: 위치 변경
- 핀치: scale 변경
- 최소 scale: 0.4
- 최대 scale: 3.0
- 투명도 최소: 0.2
- 투명도 최대: 1.0

### 버튼

- 초기화: 위치/크기/투명도 기본값 복원
- AI판단: MVP에서는 Mock 결과 표시
- 스냅: 현재 화면 캡처 저장
- 비교: CompareScreen 이동
- 설정: SettingsScreen 이동

## 7. Compare Screen

### 목적

저장한 최대 3개 후보를 한 화면에서 비교합니다.

### UI 구조

```text
┌──────────────────────────┐
│ 후보 비교                 │
├────────┬────────┬────────┤
│ 후보 1  │ 후보 2  │ 후보 3  │
│ 이미지  │ 이미지  │ 이미지  │
│ 메모    │ 메모    │ 메모    │
│ 삭제    │ 삭제    │ 삭제    │
├────────┴────────┴────────┤
│ [AI에게 3개 비교 요청]     │
└──────────────────────────┘
```

### 기능

- 후보 이미지 표시
- 빈 슬롯 표시
- 후보 삭제
- 후보 메모 수정
- 후보 상세 보기
- AI 비교 요청 버튼

## 8. Snapshot Detail Screen

### 목적

개별 후보의 큰 이미지와 메모를 확인/수정합니다.

### UI 요소

- 큰 이미지
- 메모 입력 필드
- 저장 버튼
- 삭제 버튼
- AI 판단 버튼

## 9. Personal Color Screen

### 목적

향후 퍼스널 컬러 진단 기능을 위한 화면입니다.

### MVP 처리

실제 분석은 하지 않고 준비중 화면 또는 Mock 결과를 보여줍니다.

### 문구

```text
퍼스널 컬러 진단은 밝은 자연광에서 촬영한 정면 사진을 기준으로 제공됩니다.
결과는 스타일링 참고용이며 절대적인 판단 기준은 아닙니다.
```

## 10. Settings Screen

### 기능

- 얼굴 사진 변경
- 저장된 후보 전체 삭제
- 앱 데이터 초기화
- 개인정보 안내
- 앱 버전 표시

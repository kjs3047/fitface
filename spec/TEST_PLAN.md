# FitFace Test Plan

## 1. 단위 테스트

| 테스트 | 내용 |
|---|---|
| UserProfileRepository | 프로필 저장/로드/삭제 |
| SnapshotRepository | 후보 추가/삭제/교체/최대 3개 제한 |
| CameraOverlayProvider | 위치/scale/opacity 변경 |
| AiAnalysisService Mock | Mock 결과 반환 |
| BackgroundRemovalService Mock | 입력 이미지 반환 |

## 2. 위젯 테스트

| 화면 | 테스트 |
|---|---|
| Onboarding | 등록 버튼 표시 및 이동 |
| FaceRegister | 사진 선택 버튼 표시 |
| FaceCrop | 이미지 크롭 UI 표시 |
| FacePreview | 미리보기 및 저장 버튼 표시 |
| CameraMatch | 오버레이 위젯 표시 |
| Compare | 후보 0/1/2/3개 상태 표시 |
| Settings | 초기화 버튼 표시 |

## 3. 수동 테스트 시나리오

### 시나리오 1. 최초 실행

1. 앱 설치 후 실행
2. 온보딩 표시 확인
3. 얼굴 등록 화면 이동
4. 사진 선택
5. 크롭
6. 저장
7. 카메라 화면 진입

### 시나리오 2. 카메라 매칭

1. 카메라 화면 실행
2. 얼굴 이미지 표시 확인
3. 드래그 이동
4. 핀치 확대/축소
5. 투명도 변경
6. 초기화 버튼 확인

### 시나리오 3. 스냅 저장

1. 옷 화면에 맞춘 상태에서 스냅 클릭
2. 저장 완료 확인
3. 메모 추가 선택
4. 비교 화면에서 후보 표시 확인

### 시나리오 4. 최대 3개 제한

1. 후보 3개 저장
2. 4번째 스냅 시도
3. 교체 다이얼로그 표시 확인
4. 특정 후보 교체
5. 비교 화면 반영 확인

### 시나리오 5. 데이터 초기화

1. 설정 이동
2. 앱 데이터 초기화
3. 얼굴 이미지와 후보 이미지 삭제 확인
4. 온보딩으로 이동 확인

## 4. 예외 테스트

### 카메라 권한 거부

기대 결과:

- 권한 필요 안내 표시
- 설정 열기 버튼 표시
- 앱 크래시 없음

### 얼굴 사진 없음

기대 결과:

- CameraMatchScreen 진입 불가
- FaceRegisterScreen으로 유도

### 이미지 로드 실패

기대 결과:

- 재등록 안내 표시
- 앱 크래시 없음

### 저장 공간 부족

기대 결과:

- 스냅샷 저장 실패 안내
- 재시도 가능

### 후보 3개 초과

기대 결과:

- 교체 다이얼로그 표시
- 취소 가능
- 선택 후보만 교체

# FitFace Codex Task Plan

Codex는 아래 순서대로 작업합니다. 한 번에 전체 앱을 구현하지 말고 반드시 Task 단위로 진행합니다.

## Task 01. Flutter 프로젝트 생성 및 기본 구조

### 목표

FitFace 앱의 기본 Flutter 프로젝트와 폴더 구조를 만듭니다.

### 작업

- Flutter 프로젝트 생성
- 기본 폴더 구조 생성
- 앱 테마 생성
- 라우팅 구조 생성
- Splash/Onboarding 더미 화면 생성

### 완료 기준

- 앱 실행 가능
- Splash → Onboarding 이동 가능

---

## Task 02. 로컬 데이터 모델 및 저장소 구현

### 목표

프로필, 오버레이 프리셋, 스냅샷 모델과 저장소를 구현합니다.

### 작업

- UserProfile 모델
- OverlayPreset 모델
- OutfitSnapshot 모델
- CompareSession 모델
- Repository 인터페이스/구현
- Hive 또는 JSON 저장 초기화

### 완료 기준

- 프로필 저장/로드 가능
- 스냅샷 목록 저장/로드 가능
- 최대 3개 제한 로직 구현

---

## Task 03. 얼굴 사진 등록 화면 구현

### 목표

- FaceRegisterScreen 구현

- 선택 이미지 경로 전달

- 갤러리 이미지 선택 가능

## Task 15. 테스트 및 버그 수정

### 목표

앱의 주요 흐름이 실제 기기에서 안정적으로 동작하도록 합니다.

### 테스트 흐름

1. 최초 실행 → 온보딩 → 얼굴 등록
2. 갤러리 사진 선택 → 크롭 → 미리보기 → 저장
3. 카메라 화면 진입
4. 얼굴 오버레이 드래그/핀치/투명도 조절
5. 스냅샷 저장
6. 후보 3개 비교
7. 4번째 저장 시 교체 다이얼로그
8. 메모 추가/수정
9. 후보 삭제
10. 앱 데이터 초기화

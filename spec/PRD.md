# FitFace PRD

## 1. 제품 정의

FitFace는 실제 매장 환경에서 옷을 카메라로 비추고, 사용자의 얼굴~목 이미지를 오버레이하여 색감과 분위기를 비교할 수 있게 해주는 모바일 쇼핑 보조 앱입니다.

## 2. 문제 정의

오프라인 옷매장에서 사용자는 다음 문제를 겪습니다.

- 탈의실에 들어가기 전에 옷과 얼굴의 어울림을 빠르게 확인하기 어렵습니다.
- 혼자 쇼핑할 때 객관적인 비교가 어렵습니다.
- 여러 옷 후보를 눈으로만 기억해야 합니다.
- 매장 조명, 옷 색상, 얼굴 톤의 조합을 즉석에서 비교하기 어렵습니다.

## 3. 해결 방향

사용자가 직접 옷을 입지 않아도 다음을 수행할 수 있게 합니다.

1. 후면 카메라로 실제 옷을 비춥니다.
2. 미리 등록한 얼굴~목 이미지를 카메라 화면 위에 표시합니다.
3. 사용자가 직접 위치와 크기를 맞춥니다.
4. 투명도를 조절하며 옷과 얼굴의 조화를 확인합니다.
5. 마음에 드는 후보를 스냅샷으로 저장합니다.
6. 최대 3개 후보를 비교합니다.
7. 향후 AI가 어울림과 퍼스널 컬러 기반 조언을 제공합니다.

## 4. 핵심 사용자

- 옷매장에서 혼자 쇼핑하는 일반 사용자
- 옷을 입어보기 전에 얼굴과 옷의 어울림을 빠르게 확인하고 싶은 사용자
- 여러 옷 후보를 저장하고 비교하고 싶은 사용자
- 퍼스널 컬러 기반으로 옷 선택을 보조받고 싶은 사용자

## 5. MVP 범위

### 포함

- 얼굴 사진 등록
- 얼굴~목 크롭
- 배경 제거 서비스 구조
- 후면 카메라 프리뷰
- 얼굴 오버레이
- 드래그 이동
- 핀치 확대/축소
- 투명도 조절
- 스냅샷 저장
- 최대 3개 비교
- 선택 메모
- 로컬 저장
- AI/퍼스널컬러 Mock 구조

### 제외

- 로그인
- 서버 저장
- 클라우드 동기화
- 쇼핑몰/브랜드 DB 연동
- 실제 옷 자동 인식
- 실제 퍼스널 컬러 고정밀 진단
- 실제 AI 추천 API 연동

## 6. 기능 요구사항

| ID | 기능명 | 설명 | 우선순위 |
|---|---|---|---|
| F-001 | 얼굴 사진 등록 | 갤러리 또는 카메라로 사용자 사진 등록 | Must |
| F-002 | 얼굴~목 크롭 | 얼굴부터 목까지만 남도록 사용자가 크롭 | Must |
| F-003 | 배경 제거 | 등록 이미지에서 배경 제거 후 PNG 저장 | Must |
| F-004 | 후면 카메라 실행 | 매장 옷을 비추는 실시간 카메라 화면 제공 | Must |
| F-005 | 얼굴 오버레이 표시 | 등록된 얼굴 PNG를 카메라 위에 표시 | Must |
| F-006 | 드래그 이동 | 얼굴 이미지를 자유롭게 이동 | Must |
| F-007 | 핀치 확대/축소 | 얼굴 이미지 크기 조절 | Must |
| F-008 | 투명도 조절 | 얼굴 이미지 투명도 슬라이더 제공 | Must |
| F-009 | 오버레이 초기화 | 얼굴 위치/크기/투명도 기본값 복원 | Should |
| F-010 | 스냅샷 저장 | 현재 비교 화면을 이미지로 저장 | Must |
| F-011 | 후보 슬롯 저장 | 최대 3개 후보 저장 | Must |
| F-012 | 메모 입력 | 후보 저장 시 선택 메모 입력 | Should |
| F-013 | 후보 비교 | 최대 3개 후보를 한 화면에서 비교 | Must |
| F-014 | 후보 삭제/교체 | 저장 후보 삭제 및 교체 | Must |
| F-015 | 로컬 저장 | 서버 없이 기기 내부 저장 | Must |
| F-016 | AI 판단 진입점 | 향후 AI 판단 기능 버튼 및 인터페이스 제공 | Should |
| F-017 | 퍼스널 컬러 화면 진입점 | 향후 퍼스널 컬러 진단 화면 구조 제공 | Could |

## 7. 비기능 요구사항

| 구분 | 요구사항 |
|---|---|
| 플랫폼 | Android/iOS 크로스플랫폼 대응 |
| 개발 프레임워크 | Flutter 우선 |

| 사용성 | 매장 안에서 한 손 조작 가능 |

| 네트워크 | MVP는 오프라인 동작 가능 |
